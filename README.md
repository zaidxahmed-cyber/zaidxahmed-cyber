## Active Projects

### 🔬 SPECTRA — Fileless Malware Detection & Memory Forensics
> Windows desktop app for detecting fileless malware via live process monitoring and LLM-driven DFIR

- Real-time process enumeration with heuristic risk scoring (psutil + custom scoring engine)
- Memory dump acquisition via Magnet RAM Capture → Volatility3 plugin execution
- Claude AI (claude-haiku-4-5) generates structured forensic analysis with Volatility3 plugin recommendations
- Full triage workflow: process flagged → memory dumped → AI verdict in under 10 minutes
- Stack: `React + TypeScript` · `Python Flask` · `Volatility3` · `pywebview` · `PyInstaller`

---

### 🎣 PhishGuard AI — Phishing Email Detection
> ML pipeline for classifying phishing emails with 82k+ training samples

- Fine-tuned `distilbert-base-uncased` on 6 combined phishing corpora
- Gmail API integration for live inbox scanning
- Stack: `Python` · `Scikit-learn` · `HuggingFace` · `Streamlit`

---

### 🧪 LLM Prompt Injection Lab — Controlled Attack Research
> Systematic testing of 7 prompt injection payload categories against open-source LLMs

- Categories include token smuggling, few-shot poisoning, context overflow, indirect RAG injection
- SQLite logging + HTML report generation per test run
- Covers 2025 OWASP LLM01 attack vectors including multi-agent propagation
- Stack: `Python` · `Ollama` · `SQLite`

---

### 📊 GRC Risk Assessment Framework — Enterprise Risk Platform
> Full-stack web app with 10 GRC modules built for real analyst workflows

- Risk Register, FAIR-based scoring, Compliance Mapping (NIST CSF · ISO 27001 · SOC 2)
- RBAC with 4 roles: Admin · Risk Owner · Auditor · Viewer
- Stack: `React` · `Node.js` · `PostgreSQL` · `Prisma` · `Tailwind`
